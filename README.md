# VWShell — Android-оболочка в стиле Volkswagen Discover Pro

Интерактивная оболочка (Launcher) для автомобильной Android-магнитолы:
7″, 1280×720, альбомная ориентация, Android 10–12. Kotlin + Android Views.

## Возможности
- Главный экран: сетка плиток 3×2 (Радио, Медиа, Телефон, Навигация, Автомобиль, Настройки)
  в строгой чёрно-бело-красной палитре (#050505 / #F2F2F2 / #E3182D).
- Верхняя панель: время HH:mm, название раздела, статус-индикаторы (только реальные данные).
- Медиа: управление воспроизведением через MediaSession / MediaController.
- Радио: интеграция с FM-приложением магнитолы через Intent; без тюнера — честное сообщение о недоступности.
- Телефон: запуск штатного Bluetooth-приложения, контакты/звонок через стандартные системные Intent.
- Навигация: запуск установленного навигатора (Google Maps, Яндекс и др.), выбор приложения по умолчанию.
- Автомобиль: расширяемый интерфейс под CAN-box; без CAN показывается сообщение о недоступности данных.
- Кнопки руля: обработка стандартных KeyEvent (громкость, трек, play/pause, home) + логирование неизвестных кодов.
- Без интернета, рекламы, аналитики и телеметрии. Минимальные разрешения.

## Сборка
```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
Требуется JDK 17 и Android SDK (compileSdk 34).

## CI (GitHub Actions)
Workflow `.github/workflows/android-build.yml` собирает debug APK при каждом push
и публикует его как артефакт **VWShell-Debug-APK** (вкладка Actions → последний run → Artifacts).

## Установка
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
Назначьте оболочку домашним экраном: Настройки → Приложения → VWShell → Открыть по умолчанию → Домашнее приложение,
или при первом нажатии «Домой» выберите VWShell («Всегда»).
Если прошивка магнитолы имеет функцию Auto-start — включите её и укажите пакет `com.vwshell.auto`.

## Известные аппаратные ограничения
- FM-тюнер, CAN-shina, климатика и статус сети доступны только при наличии соответствующего
  API/прошивки магнитолы. Без него эти блоки показывают нейтральное состояние, фиктивных данных нет.
- Коды кнопок руля зависят от конкретного устройства — неизвестные коды логируются (tag `KeyLog`)
  для последующей настройки.

## Структура
```
app/src/main/java/com/vwshell/auto/   — MainActivity, core (медиа, ключи, CAN-контракт), ui (экраны), widget
app/src/main/res/                     — тема, цвета, плитки, layout'ы разделов, векторные иконки
```
