# VWShell — исправления интерфейса и медиасессии

## Что изменено

- Главный экран приведён к сетке 3×2 на каждой из двух свайпаемых страниц.
- Плитки реагируют на нажатия по всей площади, включая иконку и подпись.
- Плитка Bluetooth переключает общий источник LOCAL/EXTERNAL и подсвечивается красным при выборе внешней медиасессии.
- В настройках добавлены ползунки расстояния между плитками и вертикальных отступов (меньше вертикальный отступ — выше видимая плитка).
- Верхняя панель разделов и кнопка «Назад» увеличены для удобного нажатия.
- Удалён мигающий splash-оверлей с упрощённым логотипом VW.
- Внешняя медиасессия теперь учитывает альтернативные ключи названия/исполнителя и URI обложек; обложка из URI загружается асинхронно.
- Прогресс Bluetooth/внешнего трека обновляется периодически, а кнопки пробуют стандартные media-key события, если сессия не публикует ACTION_*.
- Ползунок системной громкости сделан крупным и горизонтальным; работает и для локального, и для внешнего источника.
- NotificationListenerService экспортирован с защитой системным permission `BIND_NOTIFICATION_LISTENER_SERVICE`, чтобы Android мог подключить его для доступа к медиасессиям.
- Добавлено `READ_EXTERNAL_STORAGE` до API 33 для совместимости локальной медиатеки со старыми Android.
- Сохранена совместимость полноэкранного режима с Android 10 (API 29).

## Ограничение радио

У Android нет универсального публичного API, которым обычное приложение может менять частоту и запускать поиск на OEM FM-тюнере. Оболочка открывает штатное приложение радио и хранит UI-пресеты, но реальное управление частотой требует API/intent/broadcast конкретной прошивки магнитолы. Это не подменяется фиктивным поведением.

## Проверка

- XML-файлы прошли синтаксический разбор.
- Полная сборка `assembleDebug` в этой среде не выполнена: Gradle Wrapper не смог скачать Gradle 8.7 из-за недоступности `services.gradle.org` (DNS/network). Поэтому ZIP содержит исходники, но не проверенный APK.
- Изменения внесены в доступный архив проекта `vwshell-master.zip`. Актуальную удалённую ветку GitHub подтвердить не удалось из этой среды; перед публикацией следует сверить с последним коммитом репозитория.
